휴대폰에 앱 설치

홈 화면에 추가하면 앱처럼 바로 열 수 있습니다.

설치 방법 보기

안드로이드: Chrome에서 이 페이지를 연 뒤 ‘홈 화면에 추가’를 누르세요. 설치 창이 뜨지 않으면 Chrome 메뉴의 ‘앱 설치’ 또는 ‘홈 화면에 추가’를 선택하세요.

아이폰: Safari에서 이 페이지를 연 뒤 공유 버튼 → ‘홈 화면에 추가’ → ‘추가’를 누르세요. ‘웹 앱으로 열기’가 표시되면 켜세요.

처음에는 인터넷에 연결해 앱을 열고, 상단의 ‘오프라인 사용 준비 완료’를 확인하세요. 이후에는 인터넷 없이 입력할 수 있습니다.

설치한 앱에서 설정·내역을 확인하세요. 보이지 않으면 기존 브라우저에서 JSON 백업을 저장한 뒤 앱에서 복원하세요.
